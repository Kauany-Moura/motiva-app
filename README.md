# 📱 Motiva App

## 📌 Sobre o Projeto
Este projeto consiste em um protótipo de aplicativo desenvolvido no Figma, focado na gestão e visualização de ocorrências de forma prática, intuitiva e moderna.

O objetivo do app é facilitar o registro, acompanhamento e organização de ocorrências, oferecendo uma experiência simples para usuários e equipes responsáveis pelo monitoramento.

---

# ✨ Funcionalidades do Protótipo

## 📋 Listagem de Ocorrências
- Exibição organizada das ocorrências cadastradas
- Cards informativos contendo:
  - Ocorrência
  - Detalhes
  - Lixeira
- Scroll fluido e navegação intuitiva

---

## ➕ Cadastro de Nova Ocorrência
- Titilo da Ocorrência
- Detalhes
- Botão Adicionar

---

## 📍 Ocorrências Resolvidas
- Exibição organizada das ocorrências resolvidas
- Cards informativos contendo:
  - Ocorrência
  - Detalhes
  - Lixeira
- Scroll fluido e navegação intuitiva

---

# 🚀 Objetivo do Protótipo
O protótipo foi desenvolvido para demonstrar a experiência do usuário e validar o fluxo de gerenciamento de ocorrências antes da implementação completa do sistema.
